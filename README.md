# WordMaster – Oxford 3000

تطبيق لحفظ مفردات Oxford 3000 حسب المستويات (A1 → B2)

## المميزات
- أكثر من 3500 كلمة
- معاني عربية + أمثلة إنجليزية
- نطق أمريكي
- تكرار متباعد (Spaced Repetition)
- يعمل بدون إنترنت بعد التحميل الأول

## الاستخدام
افتح الرابط مباشرة في المتصفح، أو حمّل `index.html` وافتحه محلياً.

## المستويات
| المستوى | عدد الكلمات تقريباً |
|---------|---------------------|
| A1 | ~900 |
| A2 | ~800 |
| B1 | ~930 |
| B2 | ~910 |
